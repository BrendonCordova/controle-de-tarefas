# 📃 Controle de Tarefas

Projeto desenvolvido para colocar em prática conceitos fundamentais de programação, lógica e versionamento com Git, evoluindo de forma incremental conforme novos aprendizados são adquiridos.

Atualmente, o sistema funciona via terminal (CLI) e permite o gerenciamento de tarefas com persistência em arquivo .json, sendo ideal para estudos, experimentação e evolução contínua.

⚠️ Este projeto está em desenvolvimento ativo e passará por melhorias constantes.

## 🎯 Objetivo do Projeto

O Controle de Tarefas nasceu a partir de atividades práticas de estudo e acabou se tornando um projeto que gerou interesse real em sua evolução.

O foco principal é:

- Consolidar fundamentos de Python
- Praticar boas práticas de organização de código
- Aplicar versionamento semântico (tags e releases)
- Criar uma base sólida para futuras expansões

Com o tempo, a ideia é transformá-lo em um projeto realmente útil no meu dia a dia.
